# Code of Conduct

## Our pledge

We want nivisio to be a welcoming project for everyone, regardless of experience, identity, language, disability, appearance, ethnicity, religion or technical background. We pledge to make participation harassment-free and respectful.

## Expected behavior

- Be kind, patient and constructive.
- Assume good intent and ask clarifying questions.
- Give actionable feedback about the work, not the person.
- Respect different languages and writing systems.
- Credit other people's work.
- Keep discussions focused on the project.

## Unacceptable behavior

- Harassment, insults, threats or discriminatory comments.
- Sexualized language or imagery.
- Publishing private information without permission.
- Sustained disruption, trolling or bad-faith arguments.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This code applies in repository spaces (issues, pull requests, discussions, reviews) and when representing the project elsewhere.

## Enforcement

Report concerns privately to the maintainers through the repository profile or GitHub Security Advisories. Maintainers may remove comments, close threads, reject contributions or temporarily/permanently ban participants. Reports will be handled as confidentially as possible.

## Attribution

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
